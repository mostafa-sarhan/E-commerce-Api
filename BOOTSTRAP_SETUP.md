# Bootstrap setup

Bootstrap 5.3.8 is loaded in `index.html`.

The existing React/JS logic, API calls, routes, component structure, and custom CSS were kept intact so the website keeps the same appearance and behavior.

The CSS files were only reformatted for readability; the CSS rules themselves were not intentionally redesigned.

`node_modules` is excluded from this ZIP. After extracting the project, run:

```bash
npm install
npm run dev
```

Bootstrap is available globally after the page loads.
